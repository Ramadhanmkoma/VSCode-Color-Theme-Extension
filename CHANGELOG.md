# Change Log

All notable changes to the "techswahili" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.2.0] - 2026-10-12

### Added
- **TechSwahili Usiku** (dark) and **TechSwahili Mchana** (light): a matching pair of calm, low-glare themes built from one shared palette.
  - Full semantic highlighting plus TextMate rules for JS/TS, Python, Rust, Go, Java, C/C++, C#, PHP, HTML/JSX, CSS/SCSS, JSON/YAML/TOML, Shell, SQL, Markdown, diffs and log files
  - Clear, distinct colors for errors, warnings, info and hints across squiggles, the gutter, overview ruler, minimap, Problems panel, status bar and the Error Lens extension
  - Readable contrast for syntax colors, with comments kept muted so the code stays in focus
- `scripts/generate-themes.js` creates both theme files from their palettes

## [1.1.0] - 2025-08-20

### Added
- **TechSwahili Modern Dark**: A new contemporary dark theme featuring:
  - Modern color palette with purple (#7c3aed) as the primary accent color
  - Enhanced bracket pair colorization with 6 distinct colors
  - Improved syntax highlighting with better contrast
  - Modern UI elements with clean, minimal design
  - Better visibility for git decorations and status indicators
  - Optimized terminal colors for improved readability
  - Enhanced editor features like selection highlights and word highlighting
  - Contemporary color scheme inspired by modern design trends
